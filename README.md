# megahand-app-config

Конфигурация мобильного приложения МЕГАХЕНД (версия 0.9): баннеры главного экрана,
очередь push-уведомлений, флаги разделов. Приложение опрашивает config.json по raw-ссылке.
Публикация — из скрытой админ-страницы mhand.store или коммитом. Секретов здесь нет
и быть не должно: файл публичный по определению.
